Kebijakan Privasi

Berlaku untuk website ozancicak.my.id dan aplikasi Android azuriummovie.

Terakhir diperbarui: 29 Agustus 2026

1. Tentang layanan

azuriummovie menyediakan antarmuka untuk menemukan dan memutar film, serial, anime, serta konten hiburan lain melalui internet. Kebijakan ini menjelaskan data yang diproses ketika Anda menggunakan website atau aplikasi kami.

2. Data yang kami proses

  • Token akses dan identitas perangkat. Saat token dimasukkan, layanan memproses token serta pengenal acak perangkat untuk memvalidasi akses. Server menyimpan bentuk hash dari token dan pengenal perangkat, bukan untuk membuat profil identitas pribadi.
  • Nama atau model perangkat. Jika tersedia dari browser, informasi ini digunakan untuk menampilkan nama perangkat kepada pengguna. Ketersediaannya bergantung pada izin dan kemampuan browser.
  • Favorit, riwayat, dan progres menonton. Data ini disimpan pada penyimpanan lokal browser di perangkat Anda agar fitur koleksi pribadi dapat berfungsi tanpa akun.
  • Data teknis. Penyedia hosting, jaringan distribusi konten, dan sistem keamanan dapat memproses alamat IP, jenis browser, waktu permintaan, serta catatan kesalahan untuk mengirimkan layanan dan mencegah penyalahgunaan.
  • Data iklan. Google AdSense dan mitra Google dapat menggunakan cookie atau teknologi serupa serta memproses informasi perangkat, interaksi iklan, dan perkiraan lokasi untuk menampilkan, mengukur, dan mengamankan iklan.

3. Tujuan penggunaan data

Data digunakan untuk memvalidasi token, menjaga keamanan layanan, memuat katalog dan video, mengingat preferensi lokal, melanjutkan tontonan, menampilkan iklan, mendiagnosis gangguan, dan memenuhi kewajiban hukum yang berlaku.

4. Penyimpanan lokal dan cookie

Favorit, riwayat, progres menonton, token, dan pengenal perangkat disimpan melalui penyimpanan lokal browser. Anda dapat menghapusnya melalui pengaturan browser/aplikasi atau dengan menghapus data aplikasi. Layanan periklanan pihak ketiga dapat menggunakan cookie sesuai kebijakannya masing-masing.

5. Penyedia layanan pihak ketiga

Kami menggunakan penyedia hosting, penyedia katalog atau media, jaringan distribusi konten, dan layanan Google untuk menjalankan aplikasi. Ketika poster, subtitle, video, atau iklan dimuat dari layanan pihak ketiga, pihak tersebut dapat menerima data teknis seperti alamat IP dan informasi browser.

Pelajari cara Google memproses data pada Kebijakan Privasi Google dan Cara Google menggunakan informasi dari situs dan aplikasi mitra.

6. Pembagian dan penjualan data

Kami tidak menjual data pribadi pengguna. Data hanya dapat diproses oleh penyedia layanan yang diperlukan untuk menjalankan layanan, menjaga keamanan, menampilkan iklan, atau apabila diwajibkan oleh hukum.

7. Retensi dan pilihan pengguna

Data koleksi dan tontonan lokal tersimpan sampai Anda menghapus data browser atau aplikasi. Ikatan token tersimpan di server sampai token dilepaskan atau dihapus oleh pengelola. Anda dapat melepaskan token melalui menu perangkat, menghapus riwayat dari aplikasi, atau meminta bantuan melalui kontak di bawah.

8. Keamanan

Kami menerapkan langkah yang wajar seperti koneksi HTTPS, pembatasan percobaan akses, dan penyimpanan hash untuk mengurangi risiko akses tidak sah. Tidak ada metode penyimpanan atau pengiriman melalui internet yang dapat dijamin sepenuhnya aman.

9. Privasi anak

Layanan tidak ditujukan untuk digunakan secara mandiri oleh anak di bawah 13 tahun. Konten keluarga sebaiknya digunakan dengan pendampingan orang tua atau wali. Kami tidak dengan sengaja meminta nama, alamat, atau informasi kontak anak.

10. Perubahan kebijakan

Kebijakan ini dapat diperbarui apabila fitur, penyedia layanan, atau ketentuan hukum berubah. Tanggal pembaruan terbaru akan selalu ditampilkan pada halaman ini.
